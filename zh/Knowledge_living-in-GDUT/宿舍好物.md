# 宿舍好物

## 网络基础设施

校园网采用 **PPPoE 拨号**方式接入，登录账号为学号，密码为网络中心注册密码（即统一认证密码）。

默认情况下，校园网单个账号仅允许 **三个设备同时在线**，且宿舍内无线覆盖与稳定性有限。因此建议使用路由器进行 **PPPoE 代理拨号**，由路由器统一承载拨号，再向更多设备共享网络，从而：

- 突破单账号三设备的在线数量限制，接入更多有线 / 无线终端；
- 为智能家居等设备提供稳定、持续的连接；
- 获得更稳定的无线 / 有线网络体验。

> ⚠️ 已知限制：宿舍书桌下方的网线面板仅接入 **四芯线**，按 **T568B** 标准物理上仅支持 **100Mbps** 速率。选购设备与测速时请留意上行带宽上限。

### 设备推荐

#### 华为 / 荣耀 CD28V2 路由器


| 项目         | 参数                                                                             |
| -------------- | ---------------------------------------------------------------------------------- |
| 网络标准     | IEEE 802.11 a / b / g / n / ac                                                   |
| 最高传输速率 | 1167 Mbps                                                                        |
| 频率范围     | 双频（2.4 GHz、5 GHz）                                                           |
| 网络接口     | 1 × 10/100/1000Mbps WAN 口（网口盲插）、2 × 10/100/1000Mbps LAN 口（网口盲插） |
| 天线增益     | 3 dBi                                                                            |
| 无线加密     | WPA-PSK / WPA2-PSK                                                               |
| 认证方式     | PAP / CHAP 自适应                                                                |
| 安全功能     | 内置防火墙、DMZ、DoS 攻击保护、防暴力破解并自动屏蔽                              |
| 其他特性     | 支持 VPN、QoS、WPS，可通过手机 App 管理                                          |

该型号实测可稳定连接校园网（PPPoE 拨号）。参考价格：**15–25 元**。

#### 千兆（1Gbps）直插交换机

- 用于扩展 CD28V2 数量有限的网口，缓解接口紧张；
- 支持 10/100/1000 Mbps 速率自适应。

参考价格：**20–40 元**。

> 提示：由于宿舍面板物理上行仅 100 Mbps，交换机主要用于扩充有线接口数量，实际出口速率仍受面板四芯线限制。若对上行带宽有更高要求，可留意校园网线路或设备的后续升级。

## 智能家居设备

接入智能家居设备可提升宿舍的居住舒适度。建议以具备网关功能的设备作为接入入口，统一管理生态内的智能设备。

#### 小爱音箱 Play（蓝牙 Mesh 网关）

- 作为智能家居的接入入口，内置蓝牙 Mesh 网关；
- 可联动管理米家生态中的蓝牙 Mesh 设备，实现语音控制与场景联动。

参考价格：**50–60 元**。

#### 米家红外空调控制器

- 通过红外信号控制空调，无需改动空调电路；
- 兼容大多数支持红外遥控的传统空调，可配合米家 App / 小爱音箱实现语音或场景化开关空调。

#### 吸顶灯

- 书桌吸顶灯

#### 衣柜灯条

- 安装在衣柜内部，便于取放衣物时照明；

#### 单火智能开关

- 适用于无零线电路，可替换传统机械开关，实现对灯具的智能控制；
- 原开关建议妥善保存，搬离宿舍或毕业时需恢复原位。

## 生活设施

#### 全包床帘

- 全包式床帘可提供遮光与隐私，减少早晨强光对睡眠的干扰；
- 在广东蚊虫较多的环境下，可起到一定的防蚊、防尘作用，营造独立的个人空间。

#### 床下帘（床下 / 书桌区域帘）

- 用于床下或书桌区域，形成半私密空间；
- 可减少与舍友之间的相互打扰，适合需要安静或独立空间的居住环境。
